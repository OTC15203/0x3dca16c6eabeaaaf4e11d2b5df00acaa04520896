# Strike Project

This repository contains configuration and example code for interacting with the Strike OIDC provider and performing AES encryption.

## Files

- `strike_config.json`: Strike OIDC discovery document.
- `EncryptionExample.java`: A Java utility demonstrating AES encryption and decryption.
