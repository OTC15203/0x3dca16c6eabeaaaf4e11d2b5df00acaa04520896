# Strike Integration & Encryption Utility

This repository contains integration configuration for Strike OIDC and a utility for AES encryption.

## Contents

- `strike_config.json`: Strike OIDC discovery document and configuration.
- `EncryptionExample.java`: A Java utility class for AES encryption and decryption.
