# Strike OIDC & AES Encryption Utility

This repository contains a Strike OIDC discovery document and an AES encryption utility in Java.

## Usage

### Java Encryption Example

To compile and run the encryption example:

```bash
javac EncryptionExample.java
java EncryptionExample
```

### Strike Configuration

The `strike_config.json` file contains the OpenID Connect discovery document for Strike.
