# Strike OIDC & AES Encryption Utility

This repository contains configuration for Strike OIDC discovery and an AES encryption/decryption utility in Java.

## Project Structure

- `strike_config.json`: Strike OIDC discovery document.
- `EncryptionExample.java`: Java utility for AES encryption and decryption.
