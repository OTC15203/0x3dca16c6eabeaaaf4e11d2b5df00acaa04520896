# Strike & Encryption Utilities

This repository contains a discovery configuration for Strike's OIDC service and a Java example for AES encryption and decryption.

## Contents

- `strike_config.json`: Strike OIDC discovery document containing endpoints and supported scopes.
- `EncryptionExample.java`: A utility class demonstrating how to perform AES encryption and decryption in Java.

## Getting Started

### Strike Configuration
You can use the `strike_config.json` file to configure your OIDC client when integrating with Strike.

### Java Encryption Example
To compile and run the encryption example:
```bash
javac EncryptionExample.java
java EncryptionExample
```
