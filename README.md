# Payment & Encryption Utility

This repository contains a collection of utilities for handling Strike OIDC configuration and AES encryption in Java.

## Repository Contents

| File | Description |
| :--- | :--- |
| `strike_config.json` | Strike OIDC discovery document for authentication and API scopes. |
| `EncryptionExample.java` | A Java utility for AES-128/256 encryption and decryption. |
