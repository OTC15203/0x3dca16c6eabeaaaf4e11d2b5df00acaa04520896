# Strike & AES Utility Project

This repository contains a discovery document for Strike OIDC and a simple AES encryption/decryption utility in Java.

## Project Structure

- `strike_config.json`: Strike OIDC discovery document.
- `EncryptionExample.java`: Java utility for AES encryption and decryption.
