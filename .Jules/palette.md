## 2026-06-09 - Improving Developer Experience (DX) as UX
**Learning:** When a repository lacks a traditional web UI, the "interface" is defined as the file structure, documentation, and data formatting. Malformed files and vague names hinder developer onboarding and tool compatibility.
**Action:** Prioritize semantic filenames, valid syntax (removing appended metadata), and structured documentation in the README to improve the developer's experience.
