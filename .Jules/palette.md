## 2025-05-30 - DX as UX in Data-Only Repositories
**Learning:** When a repository lacks a traditional UI, the Developer Experience (DX) becomes the primary user interface. Descriptive filenames, valid syntax, and well-structured READMEs are critical for usability.
**Action:** Treat file structure and documentation as UX components. Prioritize fixing syntax-breaking metadata by moving it to documentation (README) rather than leaving it in source files.
