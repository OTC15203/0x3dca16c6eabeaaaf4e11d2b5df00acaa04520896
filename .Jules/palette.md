## 2025-05-14 - Developer Experience as the Primary Interface
**Learning:** In repositories without a traditional web UI, the "interface" is defined by the file structure, documentation clarity, and the ease of running examples (DX). Poor naming and syntax errors in examples significantly hinder accessibility for developers.
**Action:** Prioritize semantic file naming, valid code examples, and structured READMEs to ensure the project is accessible and intuitive to developers.
