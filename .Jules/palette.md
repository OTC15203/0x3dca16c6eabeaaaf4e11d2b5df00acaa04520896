## 2025-05-14 - Repository Structure as UI
**Learning:** In repositories lacking a traditional frontend, the "User Interface" is the Developer Experience (DX) provided by the file structure, documentation, and data validity. Renaming ambiguous files and sanitizing data to be tool-compatible (e.g., valid JSON, compilable code) are high-impact UX improvements.
**Action:** Prioritize file naming clarity and syntax integrity when working in data-only or utility-heavy repositories. Move any non-syntax metadata to README.md to maintain tool compatibility.
