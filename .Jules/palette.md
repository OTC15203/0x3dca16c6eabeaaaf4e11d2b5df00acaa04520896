## 2024-05-17 - [Micro-UX: File Validity as DX]
**Learning:** In headless repositories (no web UI), the "User Interface" is the file structure and data formatting. Broken file formats (invalid JSON, non-compiling code) are the equivalent of broken UI buttons.
**Action:** Always ensure data-heavy files (JSON, CSV) and utility code (Java, Python) are valid and formatted correctly, moving non-conforming metadata to documentation (README) instead of appending it to raw data.
