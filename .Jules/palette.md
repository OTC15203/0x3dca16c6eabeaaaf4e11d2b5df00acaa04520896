## 2024-05-21 - [Repository-as-Interface DX]
**Learning:** In repositories without a traditional GUI, the "User Interface" is the developer experience (DX). This includes file naming conventions, data validity, and structured documentation. Appending metadata directly to source/config files breaks tooling and makes the "interface" unpleasant and broken.
**Action:** Always verify that source and config files are valid for their respective formats. Move metadata from file suffixes to a central README to improve visibility and maintain file integrity.
