## 2025-05-25 - DX as UX in Code-Only Repos
**Learning:** When a repository lacks a traditional web UI, the 'interface' is defined as the file structure, documentation (README), and data formatting (Developer Experience/DX). Renaming cryptic files and cleaning non-standard metadata improves discoverability and accessibility for developers.
**Action:** Treat file structure and documentation as the primary UI in backend/utility repositories. Use descriptive filenames and clean metadata to ensure 'out-of-the-box' functionality (e.g., ensuring code compiles and JSON is valid).
